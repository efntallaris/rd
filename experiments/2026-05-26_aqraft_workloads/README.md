# AqRaft YCSB workloads a / b / c (2026-05-26)

Raw YCSB load and run output for the first AqRaft (Raft-replicated) reshard runs, one folder
per workload: `logs/workload{a,b,c}/ycsb_load_raw.txt`, `ycsb_run_raw.txt`.
No figures were kept; the plotting tools need the full collected run (ycsb/ + logs/), which is
not available for these runs.
